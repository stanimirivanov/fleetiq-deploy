## Evidence that changes the request's assumptions
- No new TCP gateway is needed. The admitted package supports Codec 8/8E, with 1280-byte frames, 16 records, 64 IO values and 256-byte variable IO. UDP, Codec 16 and commands are explicitly excluded. [Package contract](https://github.com/stanimirivanov/fleetiq-platform/blob/28823c547a4f7a5bd646a58e580c659d43e967d2/packages/teltonika/README.md)
- N simulated devices does not imply N simultaneous product connections. Current limits are eight global/two per peer, a single child executor, 15-second idle timeout and 300-second connection lifetime. [Transport](https://github.com/stanimirivanov/fleetiq-platform/blob/28823c547a4f7a5bd646a58e580c659d43e967d2/crates/server/src/tcp_ingestion/transport.rs), [executor](https://github.com/stanimirivanov/fleetiq-platform/blob/28823c547a4f7a5bd646a58e580c659d43e967d2/crates/server/src/tcp_ingestion/executor.rs)
- ACK means durable raw acceptance, not a completed semantic projection. Cross-session duplicates can receive different accepted-message IDs because identity includes a connection nonce and sequence. [Turn](https://github.com/stanimirivanov/fleetiq-platform/blob/28823c547a4f7a5bd646a58e580c659d43e967d2/crates/ingestion/src/live_session/session/turn.rs), [session](https://github.com/stanimirivanov/fleetiq-platform/blob/28823c547a4f7a5bd646a58e580c659d43e967d2/crates/ingestion/src/live_session/session.rs)
- A built-in test sender already exists, but is a bounded one-record qualification fixture, not a configurable fleet simulator. Keep it independent as a regression oracle. [Fixture](../../../local/qualification/product/device.mjs)
- The qualification issuer is disposable and uses internal hostnames. It is not a host-accessible persistent demo identity service. [Issuer](../../../local/qualification/product/issuer.mjs), [origins](../../../local/qualification/product/oidc-contract.mjs)
- Deployment pins older producer commits than the sibling HEADs. Reviewed source pins, not current sibling files, determine an installed result. [Artifact lock](../../../local/artifacts.lock.json)
- Kubernetes packaging exists, but persistent D06 acceptance is explicitly incomplete in the repository. It cannot be treated as a ready one-command local product. [Readiness](../../../docs/operations/d06-readiness.md)
